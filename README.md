# BIMO Easy to Read

Android OCR application focused on accurate, structured, offline text extraction.

## Product principles

- OCR is bundled with the application.
- No ads, telemetry, analytics, or cloud OCR.
- No runtime model download.
- Indonesian and English interface.
- Automatic Clipboard copy after successful OCR.
- Markdown and DOCX export.
- GitHub Actions is the only build and test environment.

Development is performed through pull requests. See the active draft PR for the V1 implementation.
