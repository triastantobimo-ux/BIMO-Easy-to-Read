# Phase 1 revision log

## 0.6.0-pdf-phase1

- Replaced the generic Documents entry with a dedicated PDF module.
- Added PDF Center with Android document-provider access and local recent-file metadata.
- Replaced the thumbnail-only PDF preview with a continuous AndroidX PDF workspace.
- Added native search, text selection, page navigation, bookmarks, resume position, zoom, and layout controls.
- Added share, selected-page-aware print, and OCR-current-page actions.
- Added Android S extension 18 capability gate for annotations and form filling.
- Added safe original/copy save paths and unsaved-change protection.
- Added explicit distinction between visual signatures and certificate-based digital signatures.
- Preserved zero network, analytics, advertising, and broad-storage permissions.
