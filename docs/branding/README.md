# BIMO Easy To Read Android Icon

This directory keeps the current owner-supplied launcher artwork without redrawing it.

- Master asset: `B_Focus_Lens_1254.png` (1254 x 1254)
- Google Play asset: `B_Focus_Lens_Play_Store_512.png` (512 x 512)
- Master SHA-256: `CCD9392954590EC88250B65DE7CF284EDD56F41487A1518FB501956D4EF83FF4`
- Integrated launcher resources: `app/src/main/res/mipmap-*`

The Android manifest uses `@mipmap/ic_launcher` and `@mipmap/ic_launcher_round`. Both names
use the same supplied flattened artwork so the operating system does not substitute the previous
adaptive foreground/background package. The same launcher artwork is shown in the in-app header.
